# Simulation

This repository contains simulation scripts and notebooks for biomedical research analysis.

## Description

The repository includes computational simulations and data analysis scripts, particularly focusing on research replication and extension of published methodologies.

## Contents

- `Simulations_Kim_etal_2021_update-plot.ipynb` - Jupyter notebook with simulation code and visualization updates

## Technologies Used

- **Python** - Primary programming language
- **Jupyter Notebook** - Interactive development environment
- **Scientific Libraries**: 
  - NumPy - Numerical computations
  - Matplotlib/Seaborn - Data visualization
  - Pandas - Data manipulation
  - SciPy - Statistical analysis

## Getting Started

### Prerequisites

```bash
pip install jupyter numpy matplotlib pandas scipy seaborn
```

### Running the Notebook

1. Clone the repository:
```bash
git clone https://github.com/katerina-timofeeva/simulation.git
cd simulation
```

2. Start Jupyter Notebook:
```bash
jupyter notebook
```

3. Open `Simulations_Kim_etal_2021_update-plot.ipynb` and run the cells

## Usage

The notebook contains:
- Data simulation algorithms
- Statistical analysis procedures
- Visualization and plotting functions
- Results interpretation and validation

## Research Context

This work builds upon and extends methodologies from Kim et al. (2021), providing updated analysis and enhanced visualizations for better understanding of the research findings.
